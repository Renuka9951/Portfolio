# Renuka Reddy - Developer Portfolio

A modern, high-performance developer portfolio built with React, TypeScript, and Tailwind CSS featuring dynamic cosmic canvas animations, certification showcase with upload options, project spotlight, and interactive profile customization.

---

## 🚀 Quick Start Guide (VS Code)

### 1. Prerequisites
- **Node.js**: Make sure Node.js (version 18 or higher) is installed on your computer. Download from [nodejs.org](https://nodejs.org/).
- **VS Code**: Visual Studio Code editor.
- **Git**: Installed on your system ([git-scm.com](https://git-scm.com/)).

### 2. Open Project in VS Code
1. Unzip the project folder `renuka-reddy-portfolio.zip` to your computer.
2. Open **VS Code**.
3. Go to **File** → **Open Folder...** and select the unzipped project folder.
4. Open the built-in terminal in VS Code:
   - Shortcut: ``Ctrl + ` `` (Windows/Linux) or ``Cmd + ` `` (Mac)
   - Or menu: **Terminal** → **New Terminal**

### 3. Install Dependencies
Run the following command in the terminal:
```bash
npm install
```

### 4. Run Development Server
Start the local development server:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000` (or the port shown in your terminal).

## 🌐 Deploy to GitHub & Live Hosting

### Method A: Push to GitHub Repository
1. Initialize Git in the project root:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Renuka Reddy Portfolio"
   ```
2. Create a new repository on your GitHub account (`https://github.com/new`). Name it `portfolio` or `renuka-portfolio`.
3. Link your local repo and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/Renuka9951/portfolio.git
   git push -u origin main
   ```

### Method B: Deploy Free on Vercel or Netlify (Recommended)
1. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Sign in with GitHub.
3. Click **"Add New Project"** and select your GitHub repository.
4. Build settings are detected automatically:
   - Framework: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Click **Deploy**! Your portfolio will be live in seconds with free SSL.
